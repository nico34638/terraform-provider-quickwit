# terraform-provider-quickwit

Terraform/OpenTofu provider for Quickwit 0.9, built with
`terraform-plugin-framework`. Registry address: `nico34638/quickwit`.
Design and API facts: `docs/PLAN.md`.

## Layout

- `internal/client/`: hand-written HTTP client (the Quickwit OpenAPI misses
  field options and the GET routes). Errors are `*client.APIError`; use
  `client.IsNotFound`.
- `internal/mapping/`: pure Go, no Terraform: canonical JSON of field mappings
  and tokenizers (`Canonicalize`, explicit server defaults, sorted keys, no HTML
  escaping), byte sizes and durations.
- `internal/provider/`: provider, `quickwit_index` (resource + data source),
  `quickwit_field_*` / `quickwit_tokenizer` data sources (spec-driven, in
  `field_data_sources.go`), `quickwit_source_*` resources (generic
  `sourceResource[T, M]` + `SourceCommon` embedded in each model).
- `docs/` (except `PLAN.md`) and `examples/` feed the registry docs.

## Design rules

- `quickwit_index` stays atomic: one full PUT per update, the doc mapping is a
  list of JSON strings built by the field data sources. No per-field resources.
- No false diffs: values the server rewrites (JSON, sizes, durations) use the
  semantic-equality types of `semantic_types.go`; on Read keep the prior state
  value when it is semantically equal.
- Reject at plan time (`ModifyPlan`, validators) what Quickwit would reject at
  apply time, mirroring the Rust rules (`quickwit-config`, `quickwit-doc-mapper`
  in `~/dev/rust/quickwit`). Check the Rust source before assuming an API
  behaviour.
- Immutable attributes are `RequiresReplace`; secrets are `Sensitive`.
- A new field option or source attribute needs: schema + description, model
  conversion both ways, canonical default in `internal/mapping`, unit test,
  round-trip or acceptance test, regenerated docs.

## Dev environment

- `nix develop` provides go, tofu (1.13, used by acceptance tests via
  `TF_ACC_TERRAFORM_PATH`), golangci-lint, gnupg, and enables the commit hook.
  The system tofu may be older: use the dev shell.
- Quickwit for tests: `docker compose up -d --wait` (port 7280; `--profile
  sources` adds Kafka and LocalStack).
- Do not touch a Quickwit already running on :7280 that is not the compose
  one. To test in isolation, run a separate project on other ports:
  `QUICKWIT_PORT=17280 KAFKA_PORT=19092 LOCALSTACK_PORT=14566 docker compose -p qwtest --profile sources up -d --wait`,
  then `docker compose -p qwtest down -v`.

## Checks before committing

```bash
go build ./... && golangci-lint run && go test ./...
go tool govulncheck ./...                         # known CVEs (CI: weekly too)
TF_ACC=1 go test ./... -count=1                  # needs Quickwit
TF_ACC=1 QUICKWIT_TEST_SOURCES=1 go test ./...   # + Kafka/SQS/Kinesis (--profile sources)
go generate ./...                                # docs: CI fails if docs/ is stale
e2e/run.sh                                       # end-to-end on a real cluster
```

## Commits and releases

- Commit subjects follow Conventional Commits:
  `<type>[(scope)][!]: <description>`, types `feat fix perf refactor docs test
  build ci chore revert`, `!` for breaking changes. Enforced by
  `.githooks/commit-msg` and the CI `commits` job
  (`.githooks/check-commit-msg.sh`). Scopes in use: `index`, `field`, `source`,
  `client`, `mapping`, `provider`, `e2e`.
- The subject is what users read in the release notes: describe the change for
  a provider user ("fix(index): no diff on heap_size written as 2GB"), not the
  implementation.
- Release notes are generated by goreleaser from the commits since the previous
  tag, grouped by type; `test`, `ci`, `build`, `chore` are left out.
- Release: `git tag vX.Y.Z && git push origin vX.Y.Z` (semver; breaking
  changes bump the minor while < 1.0). `.github/workflows/release.yml` builds,
  signs `SHA256SUMS` with the GPG key stored in the repo secrets and publishes
  the GitHub release; the Terraform registry (HCP Terraform public namespace)
  picks it up.
- Signing key: RSA (the registry refuses ECC), private key and passphrase in
  the `GPG_PRIVATE_KEY` / `PASSPHRASE` repo secrets.
  Register the public key by copying `release-signing-key.asc` from the file
  (`wl-copy < release-signing-key.asc`), never from terminal output: indented
  lines break `terraform init` ("error decoding signing key").
- Dependencies: Dependabot (`.github/dependabot.yml`) opens weekly PRs for Go
  modules and GitHub Actions, as `chore(deps)` / `ci(deps)` commits. The
  compose images are pinned by hand (`QUICKWIT_VERSION`, `CP_VERSION`,
  `LOCALSTACK_VERSION`).
- Never commit `.claude/`, `release-signing-key.asc` or `sandbox/`.
