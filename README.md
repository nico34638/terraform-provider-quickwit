# terraform-provider-quickwit

Terraform/OpenTofu provider for [Quickwit](https://quickwit.io) indexes and sources.

Design and roadmap: [docs/PLAN.md](docs/PLAN.md).

## Development

```bash
nix develop                # go, opentofu, golangci-lint
docker compose up -d       # Quickwit on http://localhost:7280
curl -s localhost:7280/health/readyz
go test ./...              # unit tests (no Quickwit needed)
TF_ACC=1 go test ./...     # + round-trip and acceptance tests against the local Quickwit
docker compose down -v
```

Try the provider locally with a `dev_overrides` CLI config pointing at the
directory of a `go build` binary, then run `tofu apply` in `examples/logs`.

Docs in `docs/` (except `PLAN.md`) are generated by
[tfplugindocs](https://github.com/hashicorp/terraform-plugin-docs) from the
schema descriptions and `examples/`.
